# CS-250: Software Development Lifecycle

This repository contains my final project for CS-250: Software Development Lifecycle, a course in the SNHU Computer Science program. It includes my Sprint Review & Retrospective, which reflects on the Agile and Scrum practices applied throughout the course.

## 📌 Final Project Artifact

- 📝 **Sprint Review & Retrospective**  
  A written reflection on my experience applying Agile methodology in a simulated development team. I rotated through roles including Scrum Master, Product Owner, Developer, and Tester, and documented how we adapted to shifting requirements using Scrum principles.

## 📘 Program Reflection

This course helped me understand how important it is to see things from the user’s perspective. Writing user stories showed me how to translate real needs into features that make sense, not just technically but visually and interactively too. I’ve started thinking more about how a user moves through an app, and how every detail—like layout or button behavior—affects their experience.

Agile gave me a better rhythm for how I work. I used to want everything figured out up front, but now I’m more comfortable building in steps, testing ideas early, and adjusting along the way. Sprint planning and retrospectives helped me focus, reflect, and improve without getting stuck in the big picture.

Rotating through different Scrum roles taught me a lot about teamwork. Whether I was leading or supporting, I saw how much better things go when everyone stays flexible, communicates clearly, and keeps the user in mind.

As I grow, I want to keep building tools that solve real problems—especially ones that combine clean backend logic with thoughtful, intuitive user experiences.
